# Atenua · App de OS

App web da Ordem de Serviço da Atenua Group. O vendedor anexa o PDF do pedido de venda, o app monta a OS, e a remedição e a auditoria seguem no mesmo app.

- O app inteiro está em `index.html` e é publicado pelo GitHub Pages.
- Protótipo: as OS ficam guardadas no próprio celular (IndexedDB). Ainda não há servidor.
